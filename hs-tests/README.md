# hs-tests — maquette locale pour l'atelier « Habiletés sociales »

Fichiers 100 % locaux : aucun serveur, aucune connexion Internet, aucune donnée envoyée
(tout reste dans le localStorage du navigateur du PC portable).

## Utilisation
1. Récupérer ce dossier (branche `vibe/hs-formats-locaux-8583c3`) : télécharger le ZIP de la branche, ou `git clone --branch vibe/hs-formats-locaux-8583c3 --depth 1`.
2. Ouvrir `hs-tests/index.html` en double-cliquant : ça fonctionne hors ligne.
3. Onglet « Accueil » : coller vos questions (une par ligne, format `thème | question | relance`) puis « Charger mes questions » (elles sont ensuite mémorisées en local).

## Formats à tester
QCM ensemble (vote secret P1..Pn puis révélation) · Conseil à un ami · Script à compléter ·
Émotions (visages) · Détective social (indices pour/contre) · Échelle 1-5 du groupe · Bilan de séance copiable.

Barre du haut : choix du thème, pioche sans répétition, n° de séance, minuteur, jeton de parole, nombre de patients.
